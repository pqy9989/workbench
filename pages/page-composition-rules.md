# 页面拼装规则

## 1. 页面总体结构

页面统一使用以下五个区块进行拼装：

1. **平台侧边导航区**
2. **任务信息与状态区**
3. **媒体展示区**
4. **时间轴与播放控制区**
5. **填写区**

页面外层使用 `.page-shell`，左侧为固定导航，右侧为页面工作区。

## 2. 区块与组件对应关系

| 区块 | 结构名称 | 对应组件 | 说明 |
| --- | --- | --- | --- |
| 1 | `platform-sidebar` | `components/platform-sidebar/` | 平台导航、品牌标识、平台菜单 |
| 2 | `task-header` | `components/task-header/` | 任务信息、状态、主题切换、日志入口 |
| 3 | `media-viewer` | 页面按需指定 | 视频、图片或多视角媒体展示 |
| 4 | `playback-controls` | `components/annotation-timeline/` 及页面指定组件 | 时间轴、标记点、播放、逐帧和倍速控制 |
| 5 | `fill-area` | `components/fill-area/` | 失误记录填写、程度选择、描述选择、删除和提交操作 |

## 3. 页面拼装方式

- 页面结构必须以 `pages/index-structure.html` 为基础。
- 每个页面区块使用独立的 `data-block` 标识。
- 页面需要使用某个组件时，将组件内容放入对应的 `*-slot` 容器中。
- 组件目录中的 HTML 负责结构，CSS 负责组件自身样式。
- 页面级布局样式放在页面对应的 CSS 文件中，不将页面布局规则写入组件 CSS。
- 同一个组件可以在多个页面中复用，但页面可以根据业务需要传入不同内容或数据。

## 4. 区块布局、间距与自适应规则

### 4.1 页面整体布局

- 页面采用三列布局：
  - 左侧为区块 1：平台侧边导航区。
  - 右侧工作区顶部为区块 2：任务信息与状态区。
  - 工作区下方的中间列为区块 3 和区块 4，右侧列为区块 5：填写区。
- 页面外层内边距为 `24px`。
- 所有相邻区块之间统一使用 `16px` 间距。
- 页面不得因为组件内容变化产生额外的区块间距。

### 4.2 区块之间的具体间距

- 区块 1 与右侧主工作区之间：水平间距 `16px`。
- 区块 2 与下方区块之间：垂直间距 `16px`。
- 区块 3 与区块 4 之间：垂直间距 `16px`。
- 区块 3、区块 4 与区块 5 之间：水平间距 `16px`。
- 区块 5 从区块 2 的下方开始，纵向覆盖区块 3 与区块 4 的总高度。
- 填写区内部的内容区和底部操作区之间保持 `16px` 间距。

### 4.3 区块 3 与区块 4 的联动尺寸规则

- 区块 4 的高度由时间轴、播放控制及实际引用的组件内容决定，不使用固定高度强行限制。
- 区块 3 使用中间主内容区域的剩余高度进行自适应调整。
- 区块 4 高度增加时，区块 3 高度相应减少；区块 4 高度减少时，区块 3 高度相应增加。
- 区块 3 与区块 4 之间始终保持 `16px` 垂直间距。
- 区块 3 不得覆盖区块 4，也不得因为区块 4 的尺寸变化产生额外空白。
- 区块 3 的媒体内容使用自适应尺寸，并保持原始宽高比，避免被拉伸变形。
- 区块 3 应设置合理的最小高度；当可用空间不足时，优先保证区块 4 的完整展示。
- 区块 5 的总高度跟随区块 3 与区块 4 的总高度变化；填写内容超出可视区域时，只在填写区内部滚动。

### 4.4 推荐 CSS 布局模型

页面实现时优先使用以下布局逻辑：

```css
.page-content {
  display: grid;
  grid-template-columns: minmax(0, 1fr) 401px;
  grid-template-rows: minmax(0, 1fr) auto;
  gap: 16px;
}

.media-block {
  min-height: 0;
}

.playback-block {
  min-height: 0;
}

.fill-block {
  grid-column: 2;
  grid-row: 1 / 3;
  min-height: 0;
}
```

实际页面可以根据组件的真实高度调整 `grid-template-rows`，但必须保持区块之间 `16px` 的间距和区块 3、区块 4 的联动关系。

## 5. 五个区块的内容要求

### 区块 1：平台侧边导航

- 使用 `<aside class="page-sidebar">`。
- 引用 `components/platform-sidebar/` 中的组件。
- 默认位于页面左侧，宽度由页面布局统一控制。

### 区块 2：任务信息与状态

- 使用 `<header class="page-header">`。
- 引用 `components/task-header/` 中的组件。
- 包含返回入口、任务 ID、任务名称、序列号、采集员、数据 ID、版本、状态和日志入口等信息。

### 区块 3：媒体展示

- 使用 `<section class="media-block">`。
- 用于放置主视角、辅助视角、结束帧或其他媒体内容。
- 如果页面不需要视频，可替换为图片、空状态或其他媒体组件。

### 区块 4：时间轴与播放控制

- 使用 `<section class="playback-block">`。
- 时间轴放入 `.timeline-slot`。
- 播放、暂停、上一帧、下一帧和倍速控制放入 `.controls-slot`。
- 时间轴组件优先引用 `components/annotation-timeline/`。

### 区块 5：填写区

- 使用 `<aside class="fill-block">`。
- 引用 `components/fill-area/` 中的组件。
- 填写区用于展示失误记录列表以及页面提交操作。
- 填写区内部包含 `.fill-slot` 和 `.actions-slot` 两部分。
- “合格”“不合格”“暂离”等操作按钮放入 `.actions-slot`。

## 5. 页面新增规则

新增页面时：

1. 复制 `pages/index-structure.html`。
2. 根据页面需求确定每个区块引用的具体组件。
3. 不改变五个区块的基本顺序，除非页面有明确的特殊需求。
4. 在页面文件中保留 `data-block`，便于识别和维护。
5. 页面需要新增组件时，先按照 `COMPONENTS.md` 在 `components/` 下创建组件目录。
